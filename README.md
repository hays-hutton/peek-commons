# peek — Commons Format module

This repository is a [Commons Format](https://commonsformat.dev/) 0.2 module describing
[peek](https://github.com/hays-hutton/peek), a native macOS markdown viewer, as verifiable
intent: prose specification (`commonsformat.md`), metadata (`commonsformat.toml`), and a
conformance eval suite (`evals.toml`) targeting deployment tier D1.

The module is self-contained: the prose spec, eval suite, and fixtures here are everything a
consumer needs to generate and verify an implementation.
